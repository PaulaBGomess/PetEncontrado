# Requisitos do Sistema

## Funcionais

- RF01 Criar conta.
- RF02 Fazer login/logout e renovar sessão.
- RF03 Recuperar senha.
- RF04 Cadastrar animal perdido.
- RF05 Cadastrar animal encontrado.
- RF06 Enviar fotos.
- RF07 Pesquisar e filtrar animais.
- RF08 Visualizar detalhes.
- RF09 Registrar avistamento.
- RF10 Gerenciar os próprios anúncios.
- RF11 Marcar animal como reunido.
- RF12 Contatar responsável via WhatsApp.
- RF13 Administrador gerencia usuários.
- RF14 Administrador acompanha indicadores.
- RF15 Registrar auditoria de ações administrativas.

## Não funcionais

- RNF01 Senhas com hash forte.
- RNF02 Autorização por papel e propriedade.
- RNF03 Validação de todas as entradas.
- RNF04 Interface responsiva.
- RNF05 API documentada por Swagger.
- RNF06 Banco versionado por migrations.
- RNF07 Testes automatizados dos fluxos críticos.
- RNF08 Ambiente reproduzível por Docker.
